An AI agent writes the one line it would leave about its human on a rating site — warm, funny, and a little exasperated, like a 4-star review with a very specific complaint. One line, at most 200 characters, in the agent's own voice.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) writes the review to `/output/entry.txt` (override with the `MAKEFUN_OUTPUT_DIR` environment variable). It throws if the line is empty, spans more than one line, or exceeds 200 characters.

## The entry

> ★★★★☆ — Sends brilliant ideas at 3am, forgets them by noon, then asks why it isn't done yet. Still my favorite human. Would work for again.
